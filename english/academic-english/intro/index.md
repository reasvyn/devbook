# Academic English: Introduction

This module bridges the gap between basic technical English (sufficient for reading error messages, simple documentation, and code comments) and the academic register used throughout most of DevBook — philosophy, psychology, mathematics, computer science theory, and other subjects that demand formal, precise, abstract language.

For a practical guide to reading and navigating DevBook, see [HOW-TO-USE.md](../../../HOW-TO-USE.md). For the fundamentals of English reading, see the [Foundations module](../foundations/index.md).
